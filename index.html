~/case-studies

Breakglass audit logs: ELK → PostgreSQL

zero data loss

context

Breakglass audit logging ran on ELK — heavy to operate and fragile exactly when it mattered most, during incidents.

what I did

Designed a PostgreSQL schema and a high-throughput batch-ingestion pipeline with conflict-safe upserts (ON CONFLICT DO UPDATE), and tuned indexes for fast audit retrieval.

result

The system kept ingesting with zero data loss through a major IBM Cloud outage, and the operational footprint got simpler.
